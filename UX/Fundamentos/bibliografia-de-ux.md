# Bibliografía de UX

Lecturas de UX ordenadas por necesidad (general, conversión y marketing digital, e-commerce, software de negocio): la obra con su edición y año, qué parte leer, si es evidencia, norma, práctica o libro de texto, y cuánto se leyó para armar la base.

Armada el 2026-11-22. La columna "Leído" dice cuánto se leyó de cada entrada: entero, abstract (solo metadatos o resumen del autor), resumen (fuente secundaria, ficha de tienda o buscador) o no. Las páginas web se leyeron con una herramienta que las pasa por un resumidor: "entero" quiere decir que se leyó lo que devolvió, no que se cotejó palabra por palabra. De ningún libro de la tabla se leyó el contenido; las fichas sirven para autor, edición y año. El peso de cada tipo de fuente está en [Fuentes de UX](fuentes-de-ux.md).

## Orden sugerido

Primero el vocabulario y el marco, después el criterio para mirar una pantalla y recién entonces la lectura de la necesidad propia. Es una recomendación de la base, no un hallazgo.

1. ISO 9241-210, la Tabla 1 y los seis principios (vista previa gratuita), para quien no es diseñador.
2. El diagrama de Garrett (2000), para ver de qué niveles está hecha una experiencia.
3. Norman (2013), capítulos 1 y 2, para el vocabulario: golfos y modelos conceptuales. En esta base, ese vocabulario está en [Modelo mental](../Percepcion-y-decision/modelo-mental.md) y [Principios de interacción](../Interaccion/principios-de-interaccion.md).
4. Las diez heurísticas de Nielsen, para detectar problemas al revisar una pantalla; cómo se aplican está en [Evaluación heurística](../Evaluacion/evaluacion-heuristica.md).
5. La sección de la necesidad concreta, abajo.
