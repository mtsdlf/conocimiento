# Taxonomía de Bloom

La taxonomía de Bloom clasifica los objetivos de aprendizaje por el proceso cognitivo que piden, de recordar a crear; la revisión de 2001 le sumó una segunda dimensión, el tipo de conocimiento. Sirve para clasificar y para detectar un curso que quedó todo en «recordar», no como orden de enseñanza.

Dentro de los [objetivos de aprendizaje](objetivos-de-aprendizaje.md) es la herramienta de clasificar: se aplica a un [objetivo de desempeño](objetivo-de-desempeno.md) ya escrito. Lo que la taxonomía no hace es decidir el orden del curso, que es trabajo de la [secuencia](../Secuencia-y-curriculo/secuencia-y-curriculo.md).

## De 1956 a 2001

El *Handbook I* de 1956, del dominio cognitivo, tenía seis categorías: conocimiento, comprensión, aplicación, análisis, síntesis y evaluación. La revisión de Anderson y Krathwohl (2001) las pasó a verbos (recordar, comprender, aplicar, analizar, evaluar, crear) y reordenó las dos últimas.

El cambio de fondo es que separa el sustantivo del verbo de cada objetivo. Según Krathwohl (2002), la dimensión del conocimiento tiene cuatro tipos (factual, conceptual, procedimental y metacognitivo) y la de los procesos, seis categorías con 19 procesos específicos. Un objetivo queda en una celda de esa tabla de 4 × 6.

| **Factual** | | | | | | |

| **Metacognitivo** | | | | | | |

## Jerarquía estricta o categorías que se solapan

El original suponía «a cumulative hierarchy»: dominar cada categoría simple era prerrequisito de la siguiente. La revisión lo afloja: «the requirement of a strict hierarchy has been relaxed to allow the categories to overlap». Krathwohl da un ejemplo: explicar, que es de comprender, es más complejo que ejecutar, que es de aplicar. Aun así sostiene que los procesos forman una jerarquía, «probably one that would be supported as well as was the original Taxonomy in terms of empirical evidence».

> [!IMPORTANT]
> **Los procesos forman una jerarquía (Krathwohl 2002).** Con solapamientos; Krathwohl cree que probablemente tenga el mismo respaldo empírico que el original.
>
> **La estructura acumulativa tiene problemas en los datos.** Estudios psicométricos (Furst 1981; Kreitzer y Madaus 1994; Booker 2007, citados en una tabla de *CBE-Life Sciences Education*; los originales no se abrieron) encontraron inconsistencias en la jerarquía. Las críticas de que la taxonomía no dice nada sobre cómo se aprende aparecen en notas de opinión, no en una revisión sistemática.

## Para qué usarla y para qué no

Sirve para dos cosas: clasificar los objetivos con un vocabulario común, y detectar que todos quedaron en recordar. No sirve para ordenar la enseñanza de abajo hacia arriba («primero que memoricen, después que apliquen»), porque la revisión misma dejó de afirmar que cada nivel sea prerrequisito del siguiente. El orden sale de los prerrequisitos de la tarea, en [jerarquía de aprendizaje](../Secuencia-y-curriculo/jerarquia-de-aprendizaje.md).
