# Fundamentos de datos

Fundamentos de datos reúne lo que cruza todo el tema Datos; por ahora, el recorrido para
aprender análisis de cohortes desde cero.

No es una parte del análisis de cohortes: ordena las notas de [Cohortes](../Cohortes/cohortes.md),
[Retención y churn](../Retencion-y-churn/retencion-y-churn.md) y [Lectura de cohortes](../Lectura-de-cohortes/lectura-de-cohortes.md)
para leerlas una vez, de lo que no requiere nada a lo que requiere todo lo anterior.

## El recorrido

- [Análisis de cohortes desde cero](recorrido-analisis-de-cohortes.md) — trece notas en orden, para quien nunca vio
  cohortes; al terminar se arma, se lee y se explica una tabla de retención por cohorte.
