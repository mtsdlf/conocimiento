# Alcance: DJ

El tema explica pinchar desde la técnica fundamental: las dimensiones en que dos temas se relacionan
cuando se los une (tiempo, forma, espectro, armonía, energía) y el criterio para elegirlos. Salió de
una conversación en la que se pidió algo abstracto, de principios, y no un curso de cómo usar el
equipo. El techno del sello ARTS (contundente, de pista; la prensa lo llama rave) es la estética de referencia para los
ejemplos, no el marco.

## Árbol

```

  Forma/             compás, frase y sección; alinear frases; dónde entra y sale un tema
  Espectro/          graves, medios y agudos; enmascaramiento; un solo bajo; ecualizar como repartir; volumen percibido
  Armonia/           tonalidad, qué combina y qué choca, cuánto pesa en un techno poco melódico
    ficha de análisis de tonalidad (fechada)
  Energia/           densidad, intensidad, tensión y descarga; el arco de un set
  Seleccion/         criterio para elegir; función (herramienta o pieza); coherencia y contraste; la colección como vocabulario
  Fundamentos/       escuelas de mezcla, el sonido ARTS, historia, fuentes, glosario
```

## Supuestos

- Para alguien que empieza o mezcla poco; no se corrigió.
- El equipo de referencia, cuando un ejemplo lo necesita, es el de una cabina estándar (dos o más
  reproductores y un mixer), sin nombrar modelos fuera de las fichas.
- **Idioma**: castellano rioplatense, con los términos del oficio en inglés cuando así se usan
  (beatmatching, cue, break).
