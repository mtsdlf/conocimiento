# Verificación contra el texto completo: Carga, Evaluación y Recuperación

Fecha: 2026-11-27. Alcance: todas las notas de `Entrenamiento/Carga/`, `Entrenamiento/Evaluacion/` y `Entrenamiento/Recuperacion/`. Lo de la posición ACSM 2026 sobre fuerza (en `principios-basicos.md`) no se tocó: lo verifica otro grupo.

Método. Texto completo por la API REST de Europe PMC (`/<PMCID>/fullTextXML`, solo open access) y, para manuscritos de autor que Europe PMC no sirve, la página de PMC (`pmc.ncbi.nlm.nih.gov/articles/<PMCID>/`), que respondió con un navegador común. Para encontrar versiones abiertas fuera de PMC se usó la API de OpenAlex (sin email). BMJ (bjsm.bmj.com), journals.physiology.org, la página de Ekelund 2016 en el repositorio de Amsterdam UMC y digitalcommons.uri.edu devolvieron 403 o una verificación anti-robot: esas fuentes quedan "sin acceso". Las citas en inglés de abajo están copiadas del texto descargado.

Resultados: sostiene = el texto completo dice lo mismo (en varios casos se sumó un dato); corregida = la nota decía otra cosa o le faltaba un matiz que cambia la lectura; suavizada = se bajó el tono; sin acceso = queda como estaba.
