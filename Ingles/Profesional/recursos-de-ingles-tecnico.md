# Recursos de inglés técnico

Las guías de estilo, los handbooks públicos de empresas y las guías oficiales que sostienen las notas de inglés profesional en software, con qué leer de cada una, al 2026-11-27.

Implementa la vertical [Inglés profesional en software](profesional.md).

Todos son gratuitos y en línea. Las URL se abrieron el 2026-11-27, salvo las de GitLab, cuyo texto no se pudo leer; las empresas reorganizan seguido estas páginas.

## Escribir

| Recurso | Qué leer | Para |
|---|---|---|
| [Google developer documentation style guide, "Write for a global audience"](https://developers.google.com/style/translation) | La página entera, que es corta: modismos, phrasal verbs, el *that* relativo | [Escritura técnica](escritura-tecnica.md) |
| [Microsoft Writing Style Guide](https://learn.microsoft.com/en-us/style-guide/welcome/) | "Global communications" | [Escritura técnica](escritura-tecnica.md) |
| [Google Technical Writing One](https://developers.google.com/tech-writing/one) | El curso; solo se leyó la introducción | [Escritura técnica](escritura-tecnica.md) |
| [Chris Beams, "How to Write a Git Commit Message"](https://cbea.ms/git-commit/) | Las siete reglas y la prueba del imperativo | [Escritura técnica](escritura-tecnica.md#el-commit-message) |
| [Conventional Commits 1.0.0](https://www.conventionalcommits.org/en/v1.0.0/) | La especificación y los ejemplos | [Escritura técnica](escritura-tecnica.md#el-commit-message) |
| [Google eng-practices, "Writing good CL descriptions"](https://google.github.io/eng-practices/review/developer/cl-descriptions.html) | La primera línea y los malos ejemplos | [Escritura técnica](escritura-tecnica.md#la-descripción-de-un-pull-request) |
