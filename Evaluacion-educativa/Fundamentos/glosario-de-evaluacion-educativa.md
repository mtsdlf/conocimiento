# Glosario de evaluación educativa

Los términos de la evaluación educativa, cada uno con una definición corta y la nota donde se explica. Sirve para entrar al tema por una palabra.

Las definiciones resumen las notas enlazadas, que tienen las fuentes. Los términos de toda el área Pedagogía están en otros glosarios: tamaño de efecto y metaanálisis, en el [glosario de didáctica](../../Didactica/Fundamentos/glosario-de-didactica.md); alineación constructiva, en el [glosario de diseño instruccional](../../Diseno-instruccional/Fundamentos/glosario-de-diseno-instruccional.md); y lo de la psicología en general, en el [glosario de psicología](../../Psicologia/Fundamentos/glosario-de-psicologia.md).

| Término | Definición |
|---|---|
| [Acuerdo entre correctores](../Validez-confiabilidad-y-equidad/confiabilidad.md) | Cuánto coinciden dos personas que corrigen el mismo trabajo. |
| [Aprendizaje para el dominio](../Calificacion-y-acreditacion/calificacion-por-dominio.md) (*mastery learning*) | No avanzar hasta superar un umbral en la unidad, con corrección y nuevas oportunidades. |
| [Autoevaluación](../Instrumentos/autoevaluacion-y-evaluacion-entre-pares.md) | Juicio de quien aprende sobre su propio trabajo o su propio saber. |
| [Bayesian Knowledge Tracing](../Evaluacion-adaptativa/seguimiento-del-conocimiento.md) (BKT) | Modelo que estima la probabilidad de dominar cada habilidad con cuatro parámetros: previo, aprendizaje, desliz y adivinanza. |
| [Calibración de correctores](../Validez-confiabilidad-y-equidad/confiabilidad.md) | Corregir juntos ejemplos antes de corregir, y revisar una muestra después, para que se aplique igual el criterio. |
| [Calificación por estándares](../Calificacion-y-acreditacion/calificacion-por-dominio.md) | Informar el nivel alcanzado en cada objetivo en lugar de una nota única. |
| [Confiabilidad](../Validez-confiabilidad-y-equidad/confiabilidad.md) (*reliability/precision*) | Consistencia del resultado entre repeticiones: otra tarea, otro día, otro corrector. |
| [Constructo](../Validez-confiabilidad-y-equidad/validez.md) | Lo que una evaluación intenta medir: una habilidad, un saber. |
| [DIF](../Validez-confiabilidad-y-equidad/equidad-y-sesgo.md) (funcionamiento diferencial del ítem) | Que una pregunta resulte más difícil a un grupo que a otro con el mismo nivel en lo evaluado. |
| [Efecto de testeo](../../Psicologia/Aprendizaje-y-memoria/practica-espaciada-y-recuperacion.md) | Recordar de memoria lo aprendido lo fija mejor que releerlo. |
| [Equidad](../Validez-confiabilidad-y-equidad/equidad-y-sesgo.md) (*fairness*) | Que el resultado signifique lo mismo para todos los que rinden. |
| [Espacio de conocimiento](../Evaluacion-adaptativa/espacios-de-conocimiento.md) | La estructura de estados de conocimiento posibles en un dominio, ordenados por prerrequisitos. |
| [Evaluación auténtica](../Instrumentos/tareas-de-desempeno.md) | Tarea que se parece a lo que se hace fuera del curso, con desafío cognitivo y juicio sobre la calidad. |
| [Evaluación como aprendizaje](../Propositos/evaluacion-como-aprendizaje.md) | La prueba usada como intervención: practicar respondiendo. |
| [Evaluación diagnóstica](../Propositos/evaluacion-diagnostica.md) | La que averigua qué sabe alguien antes de enseñarle, para ubicarlo. |
| [Evaluación entre pares](../Instrumentos/autoevaluacion-y-evaluacion-entre-pares.md) | Juicio de los compañeros sobre un trabajo. |
| [Evaluación formativa](../Propositos/evaluacion-formativa.md) | La que se usa, mientras se enseña, para decidir qué hacer después. |
| [Evaluación sumativa](../Propositos/propositos.md) | La que resume lo logrado al final, para aprobar, calificar o certificar. |
| [Frontera externa](../Evaluacion-adaptativa/espacios-de-conocimiento.md) | Lo que alguien está listo para aprender, según los espacios de conocimiento. |
| [Grupo de comparación](../Evaluar-un-programa/evaluacion-con-grupo-de-comparacion.md) | Personas que no hicieron el programa y se miden igual, para atribuirle la diferencia. |
| [Inflación de notas](../Validez-confiabilidad-y-equidad/inflacion-de-notas.md) | Suba de puntajes o calificaciones sin suba equivalente de lo aprendido. |
| [IRT](../Evaluacion-adaptativa/teoria-de-respuesta-al-item.md) (teoría de respuesta al ítem) | Modelo de la probabilidad de acertar según la habilidad de la persona y los rasgos de la pregunta. |
| [Ley de Campbell](../Validez-confiabilidad-y-equidad/inflacion-de-notas.md) | Cuanto más se usa un indicador para decidir, más se corrompe y más distorsiona lo que mide. |
| [Microcredencial](../Calificacion-y-acreditacion/certificados-y-microcredenciales.md) | Certificado de los resultados de un curso corto. |
| [Niveles de Kirkpatrick](../Evaluar-un-programa/niveles-de-kirkpatrick.md) | Reacción, aprendizaje, conducta y resultados: lo que se puede medir de una capacitación. |
| [Oportunidad de aprender](../Validez-confiabilidad-y-equidad/equidad-y-sesgo.md) | Que lo evaluado se haya enseñado a quien lo rinde; sin ella, el resultado no es válido. |
| [Rasch](../Evaluacion-adaptativa/teoria-de-respuesta-al-item.md) | Modelo de un solo parámetro de la pregunta, la dificultad; también una escuela de medición. |
| [Referencia a criterio](../Calificacion-y-acreditacion/referencia-a-norma-y-a-criterio.md) | Leer el resultado contra lo que había que saber hacer. |
| [Referencia a norma](../Calificacion-y-acreditacion/referencia-a-norma-y-a-criterio.md) | Leer el resultado contra cómo les fue a los demás. |
| [ROI de la capacitación](../Evaluar-un-programa/retorno-de-la-capacitacion.md) | Lo que dejó un programa, en dinero, comparado con lo que costó. |
| [Rúbrica](../Instrumentos/rubrica.md) | Tabla de criterios con la descripción de cada nivel de calidad. |
| [Subrepresentación del constructo](../Validez-confiabilidad-y-equidad/validez.md) | Que la evaluación mida solo una parte de lo que dice medir. |
| [Tarea de desempeño](../Instrumentos/tareas-de-desempeno.md) | Tarea que pide hacer algo y juzga el producto o el proceso. |
| [Test adaptativo computarizado](../Evaluacion-adaptativa/teoria-de-respuesta-al-item.md) (CAT) | Prueba que elige cada pregunta según las respuestas anteriores. |
| [Transferencia de la capacitación](../Evaluar-un-programa/transferencia-de-la-capacitacion.md) | Que lo aprendido en un curso se generalice y se mantenga en el trabajo. |
| [Validez](../Validez-confiabilidad-y-equidad/validez.md) | Cuánto sostienen la evidencia y la teoría la interpretación de un resultado para un uso. |
| [Varianza irrelevante al constructo](../Validez-confiabilidad-y-equidad/validez.md) | Que el resultado dependa de algo que no es lo evaluado. |
